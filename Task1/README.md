# Task 1. Анализ безопасности системы (As-Is)

Кейс: медицинская компания «Медикаменте», один офис, ~20 админов и ~15 медспециалистов; учёт в Excel и сканах на общем диске, 1С:Бухгалтерия (файловый режим), 1С:Торговля и склад; инфраструктура: Windows Server 2022 (AD, DNS, DHCP, файловый сервер, Exchange), ККМ и OLE с 1С.

## Отделы и роли

- Ресепшен: запись пациентов, журналы, первичный контакт.
- Врачи и медперсонал: приём, медкарты, направления на анализы.
- Касса: приём оплат, первичный ввод в таблицы.
- Бухгалтерия: проводки, отчётность, сверка с кассой.
- Склад / закупки: ТМЦ, списания, передача данных в бухгалтерию.
- IT: домен, сервера, резервное копирование (по факту — без выделенного security/data governance).

## Системы и хранилища

| Система | Назначение | Где лежат данные |
|---------|------------|------------------|
| Excel | Журналы записи, частично платежи, вспомогательные списки | Файлы на общем сетевом ресурсе |
| Файловый сервер | Сканы договоров, меддокументов, анализов (JPG/PDF) | Общие папки |
| 1С:Бухгалтерия | Учёт денег, проводки, отчётность | Файловая база на сервере |
| 1С:ТиС | Склад, ТМЦ | Интеграция с бухгалтерией |
| Outlook / Exchange | Переписка, вложения | Почтовые ящики |
| AD | Учётные записи | Не ПДн пациентов, но косвенный доступ к ресурсам |

## Типы данных и чувствительность

| Тип данных | Примеры | Класс |
|------------|---------|--------|
| Идентификация и контакт | ФИО, дата рождения, телефон, email, адрес, место работы | PII (ПДн) |
| Медицинские сведения | Диагнозы, заключения, назначения, протоколы приёма, результаты анализов | PHI / врачебная тайна |
| Финансовые | Суммы платежей, чеки ККМ, проводки, договоры с суммами | Финансовые / коммерческая тайна |
| Кадровые | Сотрудники, графики, зарплата (если ведётся в тех же контурах) | ПДн сотрудников |
| Операционные | Номенклатура ТМЦ, остатки без привязки к пациенту | Прочие / низкая персональная чувствительность |

Нет сквозной минимизации данных и проектирования privacy by design — данные копируются в Excel и письма. Lineage не формализован.
